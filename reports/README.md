## Publication Standard

A report is added here only after:

**Research → Analysis → Draft → Source Verification → Analytical Challenge → Final Analyst Review → Explicit Sign-off → Publish**

Material new evidence is handled through versioned updates rather than silently rewriting prior analytical judgements.
