# Source Handling

Published assessments in this repository use publicly available information.

## Source Priorities

Where available, collection prioritises:

1. Primary technical research and direct evidence.
2. Vendor vulnerability and security advisories.
3. Government and official reporting.
4. High-quality independent security research.
5. Reputable secondary reporting for context or facts not available from primary sources.

Material factual claims should be traceable to the underlying source used by the assessment.

## Source vs Analysis

A source establishes what it reports; it does not automatically establish every inference that can be drawn from it. Reports therefore distinguish sourced facts from analytical assessments and hypotheses.

## Information Handling

No non-public employer, client, customer or operational material is used as evidence in this repository. Internal screenshots, hostnames, IP addresses, credentials, queries, detection logic, architecture details and other protected operational information must not be committed here.

## Living Intelligence

Sources can change, disappear or be superseded. Each report therefore records an information cut-off date. Material new evidence should result in a transparent update to the assessment rather than an undocumented change to historical analysis.
